## 赵夫子怀乡赋

赵师Alvin，诚可钦挹兮！昭和纪载，诞于东京之坰。
属熙雍之嘉世，绝慆媟之逸情；矻矻昕昏，研覃坟典，期骞翮于云坰。

洎平成之中叶，掇琼枝于桂榜；辗辏幽燕，栖托皋比。
绛帷持铎，十稔有奇；沧澥阻修，莫返故坰。
玄髫彫零，疲疴潜浸；伉俪未缔，瑟柱虚扃。
敷陈 CSA 之业，洞贯华英二文；专肄讲帷，和言久屏。
每凭黉序，抒幽愫而长谣；诸生竦听，罔不泫泗沾缨。

余觌夫子羁愁之菀结，惄若搥胸；悯其桑梓之遐思，怆焉扼眄。
乃覃幽思，聿构兹器；俾于讲筵，复觌乡篆。
庶东瀛之音旨，昭豁于几筵；故壤之遐情，遥通于襟眄。
以纾羁旅之郁纡，慰征人之永眷。

## 赵师怀乡箴

赵师Alvin，东京之隽胄也。诞值昭和之纪，毓于三岛之畿。
世属熙和，不耽靡曼；志存霄汉，独励简缃。
昕夕研覃，冀抟风而直上；弦诵靡辍，期释褐以登朝。

洎平成中叶，早掇桂科；历海徼遐途，来栖蓟北。
绛帐持衡，阅十霜而未改；沧溟隔越，淹万里而莫归。
华发潜凋，形神浸以凋瘵；嘉姻未缔，鸾瑟为之虚悬。
授 CSA 之秘箓，洞达华英；专讲肄之清筵，久湮和语。
每临函丈，发幽抱以长谣；环列生徒，聆哀音而陨涕。

余观夫子羁怀蕴结，惄焉如酲；缅其桑梓遐思，怆然增慨。
遂殚冥契，构兹灵器；俾于黉塾，复睹乡文。
庶东瀛之音旨，昭显于几筵；故壤之芳踪，遥通于襟抱。
稍纾羁旅之郁纡，藉慰离人之遥眷。

## 旅師の懐思

趙Alvin といふ人、東京に生まれ侍り。昭和の年に降り、平成の世に科に登る。
滄海を隔て幽燕に至り、黌門にありて教ふること十余年なり。
故郷に帰る期なく、鬢は薄く、身は衰へ、伉儷の契もなし。
日にCSAを講じ、漢英の文に達すれど、和言を口にすること稀なり。
講筵の際、時に故山の思をうたふ。座の生徒、これを聞き、あはれと涙を落とす。
余、これを見て忍び難し。冥思を竭くして器を製り、講の座に和語を顕はしむ。
遠き東都の響き、目前に現れ、羁旅の愁を少し慰めんと欲す。

# Kotoba Live 本地模型版

不需要 OpenAI API 密钥。网页控制界面录制麦克风，Java 管理透明置顶窗口，本地引擎使用 faster-whisper 识别中文或英文，并使用 Argos Translate 翻译为日语。音频和文字由本地模型处理，不发送给 OpenAI。首次使用需要联网下载模型，模型需要数 GB 的空间，下载后可离线使用。

## 下载与使用

在 GitHub 仓库的 Actions 运行成功后，下载对应 Mac 处理器的构建产物，解压并双击“启动字幕.command”。该包包含运行环境，不需要另行安装 Java 或 Python。首次启动请保持终端打开，等待模型下载，网页允许使用麦克风。右键选择“打开”可能有助于启动未签名的程序。

在 GitHub 的 Actions 页面选择 Build macOS，点击 Run workflow，即可手动构建。公开仓库首次使用时 GitHub 可能需要启用 Actions。构建没有使用 OpenAI 或其他 API 密钥。

## 限制

本项目的自动构建和实际翻译尚未验证。macOS 版本和处理器兼容性由 GitHub 构建环境及其包含的第三方依赖决定，不能保证在旧版 macOS 运行；有需要时应提供具体版本实机测试。未签名和未公证的构建可能受到 macOS 安全设置限制。窗口置顶在全屏应用或其他桌面空间中未必生效，也不支持鼠标穿透。

语音模型按约 4 秒片段自动检测语言；中英混说、噪声、静音与截断可能降低识别效果。中文先翻译成英文再翻译成日语，可能增加误差。翻译模型的准确度有限，旧电脑可能处理不过来导致延迟累积。录音来自麦克风，捕获系统声音需要额外的虚拟音频设备。

首次启动会从模型提供方下载文件，且与模型提供方建立网络连接。Argos 与 Whisper 模型及依赖各有各的许可证，请在重新分发前检查。模型、依赖和构建产物可能包含不同开源许可。
