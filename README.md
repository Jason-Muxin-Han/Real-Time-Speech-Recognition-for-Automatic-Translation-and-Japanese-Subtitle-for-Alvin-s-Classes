# Kotoba Live

Kotoba Live 是一个将**中文语音直接转换为日语字幕**的浏览器应用。语音识别和翻译模型在浏览器中运行，无需 OpenAI API 密钥。

> 本项目仍处于测试阶段。识别准确率、翻译质量和处理速度会受到设备性能、浏览器、网络及环境噪声的影响。

## 在线使用（推荐）

[打开 Kotoba Live](https://jason-muxin-han.github.io/Real-Time-Speech-Recognition-for-Automatic-Translation-and-Japanese-Subtitle-for-Alvin-s-Classes/browser/)

1. 打开网页，选择“快速识别”或“增强识别”。
2. 点击“加载模型”，等待下载和初始化完成。
3. 点击“开始识别”，允许浏览器使用麦克风。
4. 对着麦克风说中文，日语字幕会显示在页面中。
5. 使用完毕后，点击“停止”。

首次使用需要下载较大的模型，请保持网络连接并留出足够的存储空间。浏览器通常会缓存已下载的模型，但缓存可能被清除。

## 功能

- 中文语音识别，并直接翻译为日语，不经过英文中转。
- 语音识别模型可选“快速识别”和“增强识别”。
- 自定义字幕颜色和字号。
- 在支持的浏览器中使用悬浮字幕窗口。
- 尝试使用 GPU 加速翻译，不支持时回退到 CPU。
- 语音识别和翻译在浏览器本地运行，无需输入 API 密钥。

## 技术

- **语音识别**：Whisper Tiny 或 Whisper Base
- **机器翻译**：NLLB-200 Distilled 600M
- **浏览器推理**：Transformers.js、WebAssembly 和 WebGPU
- **网页部署**：GitHub Pages

首次加载时，网页需要从 jsDelivr 下载运行库，并从第三方模型镜像 `hf-mirror.com` 下载模型。下载服务会收到网络请求和 IP 地址；录制的语音在浏览器中处理，不会发送到翻译服务。

## 已知限制

- 字幕不是即时生成的。网页按约 **1.5 秒**的片段处理音频，识别和翻译还需要额外时间。
- 处理速度跟不上时，程序会保留最新的等待片段，部分语音可能丢失。
- 较短的录音片段可能截断句子，影响识别和翻译质量。
- 模型可能在噪声、静音或语音不清晰时产生错误结果。不要将字幕用于需要完全准确的场景。
- “增强识别”可能更准确，也可能更慢；GPU 加速能否提升速度取决于设备和浏览器。
- 悬浮字幕需要支持 Document Picture-in-Picture 的浏览器。网页无法保证完全透明，也无法保证显示在所有应用上方。
- 模型下载、GPU 推理和不同设备上的实际表现仍需进一步测试。

## 本地运行

浏览器需要通过 **HTTPS** 或 `localhost` 访问网页，不能直接双击打开 `index.html`。

在仓库根目录运行：

```bash
cd browser
python3 -m http.server 8899
```

然后在浏览器打开：

```text
http://localhost:8899/
```

## 项目结构

```text
browser/
├── index.html    # 网页界面
├── app.js        # 录音、字幕和页面交互
├── worker.js     # 模型加载、语音识别和翻译
└── README.md     # 浏览器版本说明
```

仓库中还保留了早期 Mac 本地版本的源码。该版本与浏览器版的运行方式不同，其构建和旧版 macOS 兼容性尚未完整验证。
